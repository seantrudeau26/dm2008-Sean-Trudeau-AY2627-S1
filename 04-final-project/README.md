For my final project, I set out to create a 2D Batman video game. I was inspired by a game I used to play as a kid and wanted to see if I could create something cool with everything I have learned. I am very pleased with the product! The product I created was exactly how I envisioned my project, which was awesome to see that my imagination turned into reality. I was trying to create a fun experience where someone could feel like a kid again. 

There are various inputs. The mouse is used to change between non-playable screens. The arrow keys are used to move Batman. The spacebar is used to attack the enemies. The user input allows the enemies to be defeated, which is the goal of the game. 

I organized the project in a way that made sense to me. I started with a skeleton structure from the flappy bird project; this helped me stay organized. Then I used classes for the bat and bad guys to keep the code concise and applicable in draw(). Much of the code for each gameState is similar and a little customized for each level. 

The game evolves over time once the enemies are progressively eliminated. Once level 1 is complete, the user moves on to level 2, and then level 3. The last level is the hardest. 

For aesthetic purposes, I really wanted to match the Batman cartoons. I kept the enemy avatars similar to the cartoon and kept the background as an eerie Gotham. I believe I achieved this well. These choices support my interactional design. 

I faced many challenges, like figuring out how to play music without it looping or figuring out how enemies would only attack when they were visible, but I was able to work through them with AI. This made my life much easier, and I learned a lot. For example, I learned about the millis() function to track time, but AI consultations also helped me work through easy errors. This allowed me to be more efficient with my time. My project improved throughout the process because I was able to do things I had not thought were possible due to the efficiency in my work.
